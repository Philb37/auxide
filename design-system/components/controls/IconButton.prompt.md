Icon-only button (back, more menu, delete, steppers). Renders an SVG <Icon>, so the mark is optically centred.

```jsx
<IconButton icon="back" label="Back" />
```

variant: round 44 | menu 40 | step 36 | square 36 | ghost 28. Always pass label. `glyph` (‹ › + ✕ ✓ •••) still works and maps to the same icons.
